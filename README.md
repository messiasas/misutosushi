# Misuto Sushi · site

Baseado no Template 4 (Moderno). Tema escuro com as cores do salão (pedra, madeira e salmão), fontes Jost e Zen Kaku Gothic New.

## Arquivos

```
index.html  → estrutura e textos
style.css   → visual (cores e fontes nas variáveis no topo; ajustes da marca no fim do arquivo)
script.js   → interações (WhatsApp e horários no objeto CONFIG no topo)
img/        → fotos do restaurante
```

## Falta preencher

No VS Code, use Ctrl + Shift + H para trocar os marcadores:

- `{{CIDADE}}`
- `{{BAIRROS_ATENDIDOS}}`
- `{{WHATSAPP_EXIBICAO}}`
- `{{EMAIL}}`
- `{{ENDERECO}}`
- `{{CNPJ}}`
- `{{LINK_INSTAGRAM}}`
- `{{LINK_FACEBOOK}}`

Também revise com o restaurante: número do WhatsApp e horários em `script.js`, preços e itens do cardápio, nota do Google (4,8 é exemplo) e depoimentos (são exemplos).
